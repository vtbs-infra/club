# 中国大陆省市区数据

`regions.json` 是以下固定提交的 `dist/pca-code.json` 原始文件：

https://github.com/modood/Administrative-divisions-of-China/tree/c49d495b40ac73eb1a66f6eeae5f8fd10696f035

上游数据截至 2023-06-30，覆盖中国大陆 31 个省级区域，上游已停止更新。
许可原文保存在同目录 `LICENSE.txt`。区划变更或历史地名允许手动填写，不能因为未在
数据中找到地址而禁止保存。解析与选择器共用该数据，仅在打开地址编辑器时加载。

更新时从明确版本替换原始文件，更新这里的来源和日期，并运行地址解析和浏览器测试。
保留上游原始格式以便比对。`address-parser.ts` 在内存中合并直辖市的市辖区/县分组，
将省直辖县级行政单位用作城市，移除东莞、中山等城市下的乡镇级条目；乡镇和街道
始终保留在详细地址中。
