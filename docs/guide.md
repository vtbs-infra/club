# 使用指南

Club 有三种身份：普通用户、主播和平台管理员。主播账号同时保留普通用户的全部功能。

## 先了解几个概念

- **身份就是 B站 UID。** 注册时在指定直播间发送验证码，证明你拥有这个 B站账号。用户名和 UID
  注册后都不能修改，找回账号也要用同一个 B站账号再验证一次。
- **名单每月自动保存。** 每位主播的大航海名单在其时区每月最后一天 23:59 自动抓取并定稿，
  定稿后不再修改。
- **礼物单按 UID 生成。** 主播发布某个月的礼物后，该月名单上的每个 UID 都会得到一张礼物单，
  不论发布和名单定稿谁先完成。还没注册的成员也有，注册后就能在自己的账号里看到。
- **领取时冻结信息。** 提交领取时，地址和填写的内容会单独加密保存一份，之后修改地址簿不影响
  已提交的礼物单。
- **发货即结束。** 主播录入快递公司和单号后，礼物单变为“已发货”。平台不跟踪物流。

## 普通用户

**注册。** 在注册页点击“验证 B站身份”，复制验证码，打开页面给出的直播间，用自己的 B站账号
发送。验证通过后，设置用户名（3–30 位字母、数字或下划线）、显示名称和密码（8–128 个字符）。
等待验证和验证后的填写各有 10 分钟。

**找回。** 在登录页点击“忘记用户名或密码？”，输入注册时的 UID 并重新验证，就能看到用户名并
设置新密码，所有设备上的登录都会退出。无法再用原来的 B站账号发消息时，无法自助找回。

**地址。** 在账号菜单的“收货地址”中管理。可以粘贴一整段收货信息，点击“识别地址”自动填写，
识别只在浏览器里完成，核对后再保存。

**领取。** 打开“待领取”的礼物，确认礼包，选择地址，填写主播要求的信息后提交。

| 状态   | 含义                       |
| ------ | -------------------------- |
| 待开放 | 有资格，还没到领取开始时间 |
| 待领取 | 可以提交领取               |
| 待发货 | 已提交，等待主播发货       |
| 已发货 | 可以查看并复制单号         |
| 已过期 | 领取已截止，或主播提前关闭 |
| 已取消 | 主播取消了这张礼物单       |

## 主播

**发布礼物。** 在“礼物发布”中新建草稿，设置资格月份、领取时间、封面、礼包内容、各等级对应
的礼包，以及领取时需要用户填写的信息。每个资格月份只能发布一份礼物。礼包有两种发放方式：

- 仅发对应最高等级礼包：每人只得到自己等级对应的礼包；
- 逐级累计礼包：提督得到舰长和提督礼包，总督得到全部三个。

礼物默认只对有资格的登录用户可见。选择在公开首页展示后，标题、说明、资格月份和领取期限会
公开，名单和资格信息不会公开。发布后礼包和等级规则不能再修改。“关闭发布”会让所有未领取的
礼物单立即过期。

**发货。** 在“礼物单”中按礼物导出待发货清单。文件只包含导出时处于“待发货”的礼物单，导出
不会改变任何状态。发货时录入快递公司和单号；填错了可以“更正发货信息”，系统保留更正记录。
也可以填写原因取消待发货的礼物单。

**公告。** 先保存草稿再发布，可以设置级别、置顶和过期时间。发布后仍可修改，修改后读者会再次
看到未读提示。主播公告只对持有你礼物单的用户可见。

**资料。** B站昵称和直播间由 Club 从 B站读取，不能手动修改，可以在“设置”中刷新。

## 平台管理员

**初始配置。**

1. 在“B站集成”扫码登录读取账号，核对昵称和 UID 后点击“启用此账号”。读取账号用于接收
   验证码、读取主播资料和名单，与用户自己的账号无关。
2. 在同一页面添加并启用验证直播间。有多个房间时，优先级数值小的优先分配。
3. 用一个与读取账号不同的 B站账号注册一次，确认识别到的 UID 正确。

**注册主播。** 主播先注册普通账号。在“主播”页面搜索该账号，设置结算时区（例如
`Asia/Shanghai`）和是否每月同步名单。Club 会从 B站读取昵称和直播间，所以该账号必须开通了
直播间。关闭名单同步只影响以后的月份。

**名单同步。** 抓取在计划时刻后一分钟内开始才算准时。迟到但前后一致的结果会进入“等待平台
确认”，由你核对候选成员后批准或拒绝。失败的任务不会自动重试，检查原因后手动重试；每个月的
名单最多抓取三次。

**公告与主题。** 平台公告面向所有登录用户，可以单独选择在公开首页展示。“主题”页提供四套
全站主题，选择后只在你的页面预览，点击“应用到整个应用”才对所有人生效。

**系统。** “系统”页展示后台任务、直播间连接和名单失败等状态。页面报错时会显示请求 ID，
运维人员可以用它查日志。
