# 产品使用指南

Club 的界面根据账号身份进入普通用户仪表盘、主播工作台或平台管理后台。本指南按实际
操作顺序说明各区域的使用方式。

## 账号身份

| 身份                        | 默认入口     | 主要工作                                   |
| --------------------------- | ------------ | ------------------------------------------ |
| 普通用户 `USER`             | `/dashboard` | 绑定 B站 UID、领取礼物、管理地址、查询物流 |
| 主播 `CREATOR`              | `/creator`   | 发布礼物和公告、查看礼物单、导出地址并发货 |
| 平台管理员 `PLATFORM_ADMIN` | `/admin`     | 配置主播、验证直播间、名单任务和平台状态   |

公开注册创建普通用户账号。主播账号由平台管理员从已有普通用户账号中创建。

## 普通用户

### 仪表盘

登录后默认进入 `/dashboard`。页面按顺序展示：

1. Club Banner；
2. 最近五条与当前用户相关的公告；
3. 当前最需要处理的操作；
4. 与已绑定 UID 关联的礼物卡片。

操作提示会根据账号状态引导用户完成 B站绑定、补充地址或领取礼物。

### 绑定 B站 UID

1. 从账号菜单打开“B站绑定”。
2. 创建验证挑战。
3. 点击页面提供的直播间链接。
4. 使用要绑定的 B站账号发送一次性验证码。
5. 返回 Club 等待绑定状态更新。

验证码具有有效期，只能在页面指定的验证直播间使用。Club 以实际发送消息的 B站 UID
作为绑定结果。

解绑会结束当前关联。绑定记录与已经提交的礼物单仍保留各自的审计和冻结信息。

### 管理收货地址

从账号菜单打开“收货地址”，可以新增、修改、设为默认或删除地址。地址内容在服务端
使用版本化 AES-256-GCM 密钥加密。

地址簿是可编辑资料。提交领取时，Club 会为礼物单保存独立的加密地址副本；之后修改
地址簿不会改变已经提交的礼物单。

### 领取礼物

礼物卡片显示主播、资格月份、礼包内容、领取期限和当前状态。领取步骤：

1. 打开处于“待领取”的礼物单；
2. 确认礼包内容；
3. 选择已有地址或新建地址；
4. 填写主播配置的领取字段；
5. 最终确认并提交。

提交时系统会再次确认当前账号仍绑定礼物单对应的 UID。提交成功后，账号、地址、礼包
内容和领取字段值被冻结。

### 礼物状态

| 状态        | 含义                     |
| ----------- | ------------------------ |
| `CLAIMABLE` | 可以填写信息并提交领取   |
| `SUBMITTED` | 用户已提交，等待主播发货 |
| `SHIPPED`   | 已录入该礼物单的运单     |
| `COMPLETED` | 礼物单已完成             |
| `EXPIRED`   | 领取期限已结束           |
| `CANCELLED` | 主播取消了已提交的礼物单 |

物流卡片展示承运方、运单号、查询链接和已记录的物流事件。

### 公告

公告页包含平台公告，以及与用户礼物单相关的主播公告。打开公告后可以将其标记为
已读。置顶公告和较高严重级别会优先展示。

## 主播

### 概览

`/creator` 汇总当前礼物发布、待发货礼物单和名单状态。主播工作台中的数据始终属于
登录账号对应的主播档案。

### 创建礼物发布

在“礼物发布”中新建草稿，需要配置：

- 礼物标题与说明；
- 资格月份；
- 领取开始时间与截止时间；
- 礼物封面；
- 是否在公开首页展示；
- 一个或多个礼包；
- 每个礼包中的礼物项目和数量；
- 舰长、提督、总督对应的礼包；
- 礼包发放模式；
- 用户领取时需要填写的附加字段。

每个资格月份最多对应一份礼物发布。

礼物默认只对拥有资格并已登录的用户可见。主播可以在发布前选择将礼物名称、说明、
资格月份和领取期限展示在公开首页；公开展示不会暴露名单或用户资格。

### 礼包发放模式

`HIGHEST_ONLY` 只发放用户当前等级对应的礼包。

`CUMULATIVE` 按等级累计：

| 名单等级 | 获得礼包                       |
| -------- | ------------------------------ |
| 舰长     | 舰长礼包                       |
| 提督     | 舰长礼包 + 提督礼包            |
| 总督     | 舰长礼包 + 提督礼包 + 总督礼包 |

如果多个等级指向同一个礼包，系统只在礼物单中加入一次该礼包。

### 领取字段

可选字段类型：

| 类型       | 用途     |
| ---------- | -------- |
| `TEXT`     | 单行文字 |
| `TEXTAREA` | 多行文字 |
| `SELECT`   | 下拉单选 |
| `RADIO`    | 单选按钮 |
| `CHECKBOX` | 布尔确认 |

字段可以设为必填。`SELECT` 和 `RADIO` 需要配置候选项。字段键使用小写字母开头，
后续可包含小写字母、数字和下划线。

### 发布与资格匹配

草稿可以反复保存和删除。发布前系统会检查三种大航海等级都已映射到有效礼包。

发布后，标题、资格月份、礼包内容、等级规则和领取字段成为礼物单生成依据。系统查找
同一主播、同一资格月份的已定稿名单：

- 名单已经定稿：发布后立即生成礼物单；
- 名单尚未定稿：名单定稿时生成礼物单。

重复执行资格匹配不会产生重复礼物单。

关闭礼物发布会停止后续资格匹配；已经生成的礼物单继续按照各自的领取期限和状态
处理。

### 礼物单与发货

“礼物单”页面支持查看领取进度并打开订单详情。

标准处理顺序：

```text
已提交（待发货） -> 已发货 -> 已完成
```

主播可以先按礼物发布导出待发货清单。文件只包含导出瞬间处于“待发货”的礼物单，
每张礼物单占一行，包含领取时冻结的地址、礼包内容和自定义领取字段。导出只是一次
只读操作，不会锁定清单、创建批次或改变礼物单状态；领取尚未截止时，页面会提示后续
提交的礼物单不会出现在本次文件中。

发货时填写：

- 用户可识别的快递公司名称；
- 运单号；
- 可选物流查询链接。

一张礼物单只对应一张运单。主播从“待发货”礼物单直接录入运单，创建成功后整张
礼物单进入“已发货”。运单确认送达或主播明确完成后，礼物单进入“已完成”。

主播可以取消“待发货”的礼物单，并填写取消原因。

### 主播公告

主播可以创建草稿或立即发布公告，设置普通、重要提醒、紧急通知三个严重级别，选择是否置顶
以及过期时间。主播公告会展示给拥有该主播当前或历史礼物单的用户。

### 主播设置

主播可以在设置页修改自己的显示名称。B站 UID、直播间和时区由平台管理员维护。

## 平台管理员

### 主播

“主播”页面用于：

- 搜索已有普通用户；
- 创建主播档案；
- 设置显示名称、B站 UID、直播间 ID 和 IANA 时区；
- 查看已注册主播。

B站 UID 和直播间 ID 使用十进制数字字符串。

### 验证直播间

平台管理员可以添加多个验证直播间，设置名称、直播间 ID、优先级和启用状态，并执行
连接测试。

验证挑战只使用已启用房间。较低的优先级数值会优先参与分配；房间健康状态用于排序
和故障诊断。

### 名单同步

Club 为每个主播的每个自然月创建名单任务。计划时刻是该主播时区当月最后一天
`23:59:00`，准时窗口持续一分钟。

名单任务状态：

| 状态               | 含义                       |
| ------------------ | -------------------------- |
| `SCHEDULED`        | 等待计划时刻               |
| `RUNNING`          | 正在抓取和校验分页         |
| `FAILED`           | 抓取、超时或一致性校验失败 |
| `PENDING_APPROVAL` | 延迟抓取结果一致，等待确认 |
| `FINALIZED`        | 名单已经定稿               |
| `REJECTED`         | 延迟结果被管理员拒绝       |

管理员可以：

- 查看名单成员与每次抓取尝试；
- 检查原始分页证据的哈希完整性；
- 重试失败任务；
- 批准或拒绝一致的延迟结果。

定稿以整次抓取结果为单位。

### 平台公告

平台公告默认面向所有已登录用户。管理员可以设置严重级别、置顶状态、过期时间，选择
保存草稿或立即发布，并可以显式将单条公告摘要展示在公开首页。

### 主题与外观

“主题与外观”页面提供 Moe、Neon、Archive 和 Pixel 四套全局预设。选择主题会立即在当前
管理页面中预览，便于同时检查导航、卡片、表单、状态和浮层；此时不会影响其他访问者。

- “应用主题”将当前预览保存为整个 Club 部署的主题；
- “取消预览”恢复已经应用的主题；
- 离开页面会自动丢弃尚未应用的预览；
- 应用失败时保留预览，管理员可以重试或取消。

应用后的主题覆盖公开页面、认证页面、普通用户工作台、主播工作台和平台管理后台。主题
只改变外观，不改变页面结构、业务流程或权限。其他已经打开的客户端会在下次完整加载时
读取新主题。

### 系统

系统页展示：

- 应用版本；
- PostgreSQL 与对象存储状态；
- B站直播间连接状态；
- 名单调度状态；
- 物流刷新状态；
- 近期名单失败与证据完整性警告。

接口错误会返回请求 ID，可用于在结构化日志中定位对应请求。
