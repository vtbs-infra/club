# 产品使用指南

Club 的界面根据账号身份进入普通用户仪表盘、主播工作台或平台管理后台。本指南按实际
操作顺序说明各区域的使用方式。

## 公开首页

`/` 无需登录即可访问，展示产品说明、当前明确公开的礼物和平台公告，以及登录或注册
入口。公开首页只读取已经发布、仍在展示期限内且显式标记为公开的内容：

- 主播可以决定一份礼物是否展示标题、说明、封面、资格月份和领取期限；
- 平台管理员可以决定一条平台公告是否展示标题、摘要、级别和发布时间；
- 名单成员、用户资格、领取信息和收货地址不会公开；
- 公开礼物不提供匿名资格详情，访客需要登录后由自身 UID 检查礼物单。

已登录用户停留在公开首页时不会被自动跳转，可以主动进入自己的工作台。平台应用的
Moe、Neon、Archive 或 Pixel 主题同时覆盖公开首页和所有登录后页面。

## 账号身份

| 身份                        | 默认入口     | 主要工作                                   |
| --------------------------- | ------------ | ------------------------------------------ |
| 普通用户 `USER`             | `/dashboard` | 领取礼物、管理地址、查看与复制发货信息     |
| 主播 `CREATOR`              | `/creator`   | 发布礼物和公告、查看礼物单、导出地址并发货 |
| 平台管理员 `PLATFORM_ADMIN` | `/admin`     | 配置主播、验证直播间、名单任务和平台状态   |

公开注册先验证 B站 UID，完成后才创建普通用户账号。主播账号由平台管理员从普通用户账号中
创建。主播账号同时保留普通用户仪表盘、地址、领取和发货信息查看能力，可以在两个工作区之间
切换。

## 普通用户

### 仪表盘

登录后默认进入 `/dashboard`。页面按顺序展示：

1. Club Banner；
2. 最近五条与当前用户相关的公告；
3. 当前最需要处理的操作；
4. 与已验证 UID 关联的礼物卡片。

操作提示会根据账号状态引导用户补充地址或领取礼物。

### 注册、登录与账号找回

1. 打开 `/register`，点击“验证 B站身份”。
2. 进入页面指定的直播间，使用自己的 B站账号发送一次性验证码。
3. 回到原浏览器，确认已验证的 UID 后设置用户名、显示名称和密码。
4. 注册成功后使用用户名与密码登录。

等待验证和验证后的提交窗口分别为 10 分钟。只有完成验证才创建正式账号；一个 UID
只能注册一个账号。用户名为 3–30 位英文字母、数字或下划线，统一保存为小写，登录忽略
大小写。密码为 12–128 个字符。用户名和 UID 注册后不可更改，显示名称可在“账号”页修改。

忘记用户名或密码时，从登录页打开“忘记用户名或密码？”，输入注册时的 B站 UID，在指定
直播间重新发送验证码。验证后页面显示用户名，可以设置新密码。此前所有登录会话和旧
找回证明会失效，需要重新登录。已注册 UID 不通过再次注册创建新账号，应直接找回。

在“账号”页输入原密码也可修改密码，同样会退出全部会话。平台不收集邮箱，不需要邮件
验证。如果无法使用原 B站账号发送消息，就无法自助找回该账号。

### 管理收货地址

从账号菜单打开“收货地址”，可以新增、修改、设为默认或删除地址。地址内容在服务端
使用版本化 AES-256-GCM 密钥加密。

地址簿是可编辑资料。提交领取时，Club 会为礼物单保存独立的加密地址副本；之后修改
地址簿不会改变已经提交的礼物单。

### 领取礼物

礼物卡片显示主播、资格月份、礼包内容、领取期限和当前状态。领取步骤：

1. 打开处于“待领取”的礼物单；
2. 确认礼包内容；
3. 选择已有地址或新建地址；
4. 填写主播配置的领取字段；
5. 最终确认并提交。

提交时系统会再次确认当前账号的 UID 与礼物单一致。提交成功后，账号、地址和领取字段值被冻结；套餐分配和发布内容在资格生成时已固定。

### 礼物状态

| 状态        | 含义                         |
| ----------- | ---------------------------- |
| `UPCOMING`  | 已有资格，尚未到领取开始时间 |
| `CLAIMABLE` | 可以填写信息并提交领取       |
| `SUBMITTED` | 用户已提交，等待主播发货     |
| `SHIPPED`   | 主播已确认发货，平台流程结束 |
| `EXPIRED`   | 截止时间已到或发布提前关闭   |
| `CANCELLED` | 主播取消了已提交的礼物单     |

发货信息展示快递公司和运单号，用户可以复制单号。平台不查询运输轨迹或签收状态。主播更正单号后，此处显示当前发货信息。

### 公告

公告页包含平台公告，以及与用户礼物单相关的主播公告。打开公告后可以将其标记为
已读。已读状态对应打开时的公告版本；发布者修改正文后，新版本会重新显示为未读。
置顶公告和较高严重级别会优先展示。

## 主播

### 概览

`/creator` 汇总当前礼物发布、待发货礼物单和名单状态。主播工作台中的数据始终属于
登录账号对应的主播档案。

### 创建礼物发布

在“礼物发布”中新建草稿，需要配置：

- 礼物标题与说明；
- 资格月份；
- 领取开始时间与截止时间；
- 礼物封面；
- 是否在公开首页展示；
- 一个或多个礼包；
- 每个礼包中的礼物项目和数量；
- 舰长、提督、总督对应的礼包；
- 礼包发放模式；
- 用户领取时需要填写的附加字段。

每个资格月份最多对应一份礼物发布。

礼物默认只对拥有资格并已登录的用户可见。主播可以在发布前选择将礼物名称、说明、
资格月份和领取期限展示在公开首页；公开展示不会暴露名单或用户资格。

### 礼包发放模式

`HIGHEST_ONLY` 只发放用户当前等级对应的礼包。

`CUMULATIVE` 按等级累计：

| 名单等级 | 获得礼包                       |
| -------- | ------------------------------ |
| 舰长     | 舰长礼包                       |
| 提督     | 舰长礼包 + 提督礼包            |
| 总督     | 舰长礼包 + 提督礼包 + 总督礼包 |

如果多个等级指向同一个礼包，系统只在礼物单中加入一次该礼包。

### 领取字段

可选字段类型：

| 类型       | 用途     |
| ---------- | -------- |
| `TEXT`     | 单行文字 |
| `TEXTAREA` | 多行文字 |
| `SELECT`   | 下拉单选 |
| `RADIO`    | 单选按钮 |
| `CHECKBOX` | 布尔确认 |

字段可以设为必填。`SELECT` 和 `RADIO` 需要配置候选项。字段键使用小写字母开头，
后续可包含小写字母、数字和下划线。

### 发布与资格匹配

草稿可以反复保存和删除。发布前系统会检查三种大航海等级都已映射到有效礼包。

发布后，标题、资格月份、礼包内容、等级规则和领取字段成为礼物单生成依据。系统查找
同一主播、同一资格月份的已定稿名单：

- 名单已经定稿：发布后立即生成礼物单；
- 名单尚未定稿：名单定稿时生成礼物单。

重复执行资格匹配不会产生重复礼物单。

关闭礼物发布会停止后续资格匹配，未领取订单会立即显示为“已过期”，并展示关闭时间和原因。
已经提交、发货或取消的礼物单保留原状态继续处理或查阅。

### 礼物单与发货

“礼物单”页面支持查看领取进度并打开订单详情。

标准处理顺序：

```text
已提交（待发货） -> 已发货（平台流程终点）
```

主播可以先按礼物发布导出待发货清单。文件只包含导出瞬间处于“待发货”的礼物单，
每张礼物单占一行，包含领取时冻结的地址、礼包内容和自定义领取字段。导出只是一次
只读操作，不会锁定清单、创建批次或改变礼物单状态；领取尚未截止时，页面会提示后续
提交的礼物单不会出现在本次文件中。

发货时填写：

- 用户可识别的快递公司名称；
- 运单号。

每张礼物单只保存一份发货信息。主播确认发货后进入“已发货”，平台流程到此结束。

填错快递公司或单号时，点击“更正发货信息”并保存；系统保留更正审计和首次发货时间，不回退状态。多人同时修改时，后提交者需要刷新后重新确认。

主播可以取消“待发货”的礼物单，并填写取消原因。

### 主播公告

主播先保存公告草稿，再通过独立操作发布；可以设置普通、重要提醒、紧急通知三个严重级别，
选择是否置顶以及过期时间。已发布公告可以直接更新内容，也可以撤下后修订并重新发布；只有
从未发布的草稿可以删除。主播公告会展示给拥有该主播当前或历史礼物单的用户。

### 主播设置

主播设置页展示当前 B站 UID、显示名称、规范直播间和最近同步时间。UID 是主播身份来源，
不能解除或替换；显示名称和直播间由 Club 从 B站读取，不支持手动覆盖。主播可以点击
“刷新 B站资料”重新同步昵称和直播间。

名单结算时区和月末同步开关由平台管理员维护，与主播账号能否登录或使用用户功能无关。

## 平台管理员

### 主播

“主播”页面用于：

- 按用户名、显示名称或 UID 搜索普通用户；
- 从该账号的已验证 UID 注册主播档案；
- 设置 IANA 结算时区和未来的月末名单同步开关；
- 查看已注册主播，并从 B站刷新显示名称和规范直播间。

注册时，Club 以已验证 UID 查询 B站资料。账号必须拥有可用直播间；UID、显示名称和
直播间不能由平台管理员填写或覆盖。

### B站集成

管理员先配置一个平台读取账号，用于身份验证弹幕、主播资料和舰长名单读取：

1. 点击“扫码登录 B站”，手机扫码并确认。
2. 核对页面显示的昵称、头像和 UID，点击“启用此账号”。
3. 添加或启用验证直播间，等待连接健康后再开始普通用户注册。

刷新页面可以继续当前会话的扫码任务；二维码过期后重新申请。更换账号期间，原有效账号
继续读取，直到新账号启用。系统自动检查和续期；出现“需要重新扫码”时重新登录即可。
“暂时不可达”表示上游连接故障，不等于账号已经退出。

“断开连接”会让 Club 停止使用该读取账号，注册、找回和 B站数据读取暂停；已有用户仍能
正常登录，已验证且未过期的注册或找回证明仍可提交。该操作不会退出用户的其他 B站设备。

验证房间支持名称、直播间 ID、优先级和启用状态。只向实际健康的启用房间分配挑战，
较小的优先级数值优先。连接测试通过仅表示鉴权可用；后台另行显示最近真实 UID 样本时间。
首次配置应由不同账号发码并完成一次注册或找回，以核对实际发送 UID。

### 名单同步

Club 为每个主播的每个自然月创建名单任务。计划时刻是该主播时区当月最后一天
`23:59:00`，准时窗口持续一分钟。

名单任务状态：

| 状态               | 含义                             |
| ------------------ | -------------------------------- |
| `SCHEDULED`        | 等待计划时刻                     |
| `READY`            | 抓取结果已完整保存，等待内部定稿 |
| `RUNNING`          | 正在抓取和校验分页               |
| `FAILED`           | 抓取、超时或一致性校验失败       |
| `PENDING_APPROVAL` | 延迟抓取结果一致，等待确认       |
| `FINALIZED`        | 名单已经定稿                     |
| `REJECTED`         | 延迟结果被管理员拒绝             |

管理员可以：

- 查看定稿成员、待确认候选成员与每次抓取尝试；
- 检查原始分页证据的哈希完整性；
- 重试失败任务；
- 批准或拒绝一致的延迟结果。

自动任务只执行首次抓取。失败和被拒绝的任务不会在后台自行重试，由管理员检查原因后
显式使用剩余机会；每个任务最多三次尝试。定稿以整次抓取结果为单位。

`READY` 表示采集成功、内部定稿尚未完成，后台会重试定稿，无需重新抓取或消耗尝试次数。

### 平台公告

平台公告默认面向所有已登录用户。管理员可以设置严重级别、置顶状态、过期时间，选择
保存草稿后发布，并可以显式将单条公告摘要展示在公开首页。已发布公告可以在线更新、撤下
和重新发布；重新发布后会作为新版本重新显示为未读。

### 主题与外观

“主题与外观”页面提供 Moe、Neon、Archive 和 Pixel 四套全局预设。选择主题会立即在当前
管理页面中预览，便于同时检查导航、卡片、表单、状态和浮层；此时不会影响其他访问者。

- “应用主题”将当前预览保存为整个 Club 部署的主题；
- “取消预览”恢复已经应用的主题；
- 离开页面会自动丢弃尚未应用的预览；
- 应用失败时保留预览，管理员可以重试或取消。

应用后的主题覆盖公开页面、认证页面、普通用户工作台、主播工作台和平台管理后台。主题
只改变外观，不改变页面结构、业务流程或权限。其他已经打开的客户端会在下次完整加载时
读取新主题。

### 系统

系统页展示：

- 应用版本；
- PostgreSQL 与对象存储状态；
- B站直播间连接状态；
- 名单调度状态；
- 礼物封面回收状态；
- 近期名单失败与证据完整性警告。

接口错误会返回请求 ID，可用于在结构化日志中定位对应请求。
